MineBox 1.3.1 installation
==========================

This release fixes permission-denied errors for backups, restore, deletion,
server.properties editing, logs, worlds, and scheduled maintenance.

Install once:

  cd /path/to/minebox-v1.3.1
  sudo bash install.sh

The installer is the only step that needs sudo. After installation, MineBox's
normal menus use password-free, tightly limited service controls and shared
file permissions. Log out and back in once after installation, then run:

  cd /opt/minebox
  python3 main.py
