MINEBOX FIXED BUILD

This build restores the working curses dashboard and arrow-key menus while keeping the added features.

1. Back up your current folder if desired.
2. Extract this ZIP.
3. Copy all extracted files into:
   /media/sf_MineBox-OS/minebox
4. In Debian run:

   cd /media/sf_MineBox-OS/minebox
   python3 -m py_compile main.py menu.py server.py status.py services/*.py
   python3 main.py

The first screen should be the curses MineBox dashboard. Press Enter to open the menu.
The menu includes Minecraft Server, Live Console, Players, Backups, Server Settings,
MineBox Settings, System, About, and Exit MineBox UI.
